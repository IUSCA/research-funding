# Trigger prompts

Use these in a fresh session to check that each skill loads when it should.
Each prompt names the skill that should load first. Others may load too.
Step 7 of `MAINTAINING.md` explains the test.

| Prompt | Expected skill |
| --- | --- |
| I want to submit an R01 in February. Help me plan backward from the deadline. | `planning-a-proposal` |
| What do I need to do between now and the NIH deadline, and when is IU's internal deadline? | `planning-a-proposal` |
| Is there an NIH or foundation funding opportunity for my aging and sleep project? | `finding-funding-opportunities` |
| Should this be an R21 or an R01? | `finding-funding-opportunities` |
| Review my Specific Aims page against what NIH reviewers look for. | `writing-specific-aims` |
| How should I structure the Approach section under the new NIH review criteria? | `writing-the-research-strategy` |
| What does "rigor of prior research" mean, and where does it go? | `writing-the-research-strategy` |
| I have cohort counts from a biobank. How do I use them as preliminary data and justify my sample size? | `using-preliminary-data-and-feasibility` |
| Do I need preliminary data for an R21? | `using-preliminary-data-and-feasibility` |
| Build a five-year budget with a postdoc, core facility services, and a subaward. | `budgeting-a-proposal` |
| How do I calculate person months for a 9-month faculty appointment? | `budgeting-a-proposal` |
